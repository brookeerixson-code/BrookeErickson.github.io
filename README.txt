# Brooke Erickson Portfolio Website

This is a clean, responsive, static personal portfolio website.

## Files
- `index.html` — all editable page content
- `style.css` — colors, fonts, spacing, layout, and responsive design
- `script.js` — mobile navigation behavior
- `assets/` — photos and editable resume

## Pages
The site uses four scrollable sections that function as the requested pages:
Home, About, Portfolio, and Contact.

## Editing
Open `index.html` in a text editor and change the text directly. Replace photos in `assets/` while keeping the same filenames, or update the image filenames in `index.html`.

The main colors are at the top of `style.css` under `:root`, so the palette can be changed in one place.

## Running locally
Double-click `index.html` to preview it, or open it in any browser.

## Publishing
This static site can be published on GitHub Pages, Netlify, Vercel, or another static hosting service. The contact form currently uses a mailto action so it opens the visitor's email application; a form service can be connected later if you want submissions stored online.
